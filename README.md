Sistem informasi produk sederhana berbasis **PHP Native** dan **Bootstrap 5** secara modular tanpa database.

Fitur & Keunggulan
- **Modular**: Pemisahan tampilan (`UI`) dan logika bisnis.
- **Tanpa Database**: Menggunakan *array* PHP untuk data produk.
- **Responsif**: Tampilan rapi dengan Bootstrap 5.

📁 Struktur File
- `config.php` - Konfigurasi dasar proyek.
- `functions.php` - Fungsi pengolah data *array* produk.
- `products.php` - Komponen tampilan daftar produk.
- `index.php` - Halaman utama penampung modul.
